# Project Description

LavernaEvents is a modern Event Management Platform that enables users to manage different types of events from one application.

Supported Events

- Wedding
- Reception
- Engagement
- Birthday
- Anniversary
- Housewarming
- Corporate Events
- Religious Events
- Conferences
- Family Functions
- Private Events
- Custom Events

Main Features

- Membership Plans
- Event Management
- Invitation Templates
- WhatsApp Invitation Sharing
- Guest Management
- Guest Response Tracking
- QR Code Generation
- Photographer Portal
- Gallery Management
- AI Face Recognition
- Dashboard Analytics
- Admin Panel
